# DeanOS

DeanOS is a browser-based desktop environment built as a personal portfolio project.
It simulates a full operating system experience — complete with a boot sequence,
login screen, desktop, taskbar, and windowed applications — all running in the browser.

## Tech Stack

- React 18 + TypeScript
- Tailwind CSS + Framer Motion
- Zustand (state management)
- Vite

## Key Features

- Cinematic boot sequence with POST scrolling and animated logo
- Login screen with password auth, shake animation, and hint system
- Draggable, resizable, and maximisable application windows
- Taskbar with start menu and system tray
- System tray: clock, calendar with live seconds, battery, wifi, volume, notifications
- Toast notification system with auto-dismiss
- Terminal with 22 commands, tab completion, history, and matrix animation
- Browser app with portfolio project pages
- Fully client-side — no backend required
